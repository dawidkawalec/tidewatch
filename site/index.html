The lamps

Four colors, nothing to read.

  • Working

    Claude is coding, running tests or researching. The lamp breathes softly while it works.

  • Needs you

    A tool call waits for your approval, or Claude asked a question. The list shows which command.

  • Ready for review

    Claude finished its turn. Read the result, reply or move on, and the lamp settles.

  • Idle

    The session is open and waiting for your next prompt. Closed sessions disappear by themselves.

How it works

Out of the way until you need it.

  1. 01

    Glued to the edge

    The column floats on the right edge above every window and never takes focus, so typing in your editor is never interrupted.

  2. 02

    Hover for the list

    The panel wells out of the column like a drop of glass: project, what Claude is doing and how long it has been in that state.

  3. 03

    Click to jump

    The right VS Code window comes to the front with that session's Claude tab open. Terminal sessions bring their terminal forward.

  4. 04

    Hear it, too

    A soft sound when a session needs your approval or finishes a turn, so you can keep working in another window.

Privacy

Everything stays on your Mac.

  • Only an update check

    Once a day Tidewatch asks this page whether a new version is out, and that is its only connection. No account, no analytics, no telemetry, nothing about your sessions.

  • Built on Claude Code's own hooks

    A tiny helper writes one small status file per session: project folder, status and a one-line preview of the tool call waiting for you. To list every open tab, Tidewatch also reads Claude Code's list of running sessions and each conversation's title. No prompts, no code, and nothing leaves your Mac.

  • Connect and disconnect in one click

    Tidewatch adds only its own entries to ~/.claude/settings.json, backs the file up first and removes exactly those entries when you disconnect.

  • Signed and notarized

    Built with an Apple Developer ID and checked by Apple's notary service, so macOS opens it without warnings.

Install

Up and running in a minute.

  1. 01

    Download

    Open the DMG and drag Tidewatch to your Applications folder.

  2. 02

    Connect

    Open it and choose Connect to Claude Code from the lamp icon in the menu bar.

  3. 03

    Work as usual

    Start or resume a session. The first time you click one, VS Code asks to open the Claude link: tick "Do not ask me again".

FAQ

Questions

Is Tidewatch made by Anthropic?

No. It is an independent tool by Dawid Kawalec. Claude and Claude Code are trademarks of Anthropic.

Does it slow Claude Code down?

No. The helper finishes in milliseconds, never blocks and never changes what Claude does. If anything goes wrong it simply exits.

A session does not show up. Why?

Claude Code runs hooks only in folders you trust. Open the folder in Claude Code once and accept the trust prompt. If nothing shows up at all, choose Connect to Claude Code in the menu bar again.

Does it work with the Claude Code CLI?

Yes. CLI sessions get their lamp too. A click brings Terminal, iTerm, Ghostty or Warp to the front, or opens the folder in VS Code when the session runs in VS Code's terminal.

How do updates work?

Tidewatch checks for a new version once a day and asks before installing it. You can also choose Check for Updates… in the menu bar. Every update is signed, and Tidewatch refuses one that is not.

What about Intel Macs?

Tidewatch is built for Apple silicon only for now.

How do I remove it?

Choose Disconnect in the menu bar, quit Tidewatch, then delete the app and the folder ~/Library/Application Support/Tidewatch. Your Claude Code settings are back to how they were.
