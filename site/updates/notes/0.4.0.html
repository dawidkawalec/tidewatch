Tidewatch 0.4.0

New in this release

  • Every open tab, grouped by window. Tidewatch now shows every Claude Code tab you have open, also the ones that were quiet since Tidewatch started. The tabs of one VS Code window sit together; a window with several tabs gets a header in the list, and each tab is named after its conversation, as on the VS Code tab.
  • Names stay put. A lamp is named after its window's folder and no longer changes when the agent works in another folder.
  • No more empty tabs. A Claude tab you have not typed in yet stays hidden until its conversation starts.
  • Restart Tidewatch from the widget's right-click menu or the menu bar.
  • Up to ten lamps fit in the column.

Install

Already on 0.3.0? Tidewatch offers this version on its own, or choose Check for Updates… in the menu bar. New here? Open Tidewatch-0.4.0.dmg, drag Tidewatch to Applications, start it and choose Connect to Claude Code in the menu bar.

Requires macOS 14.4+ on Apple silicon.
