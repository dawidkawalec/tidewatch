Tidewatch 0.4.3

New in this release

  • Long lists scroll. With many sessions open, scroll over the open panel with the trackpad or the mouse wheel to reach the last rows. Small chevrons show when there is more above or below, and the list opens at the top again.
  • Hovering a row highlights its lamp also while the list is scrolled.

Install

Already on 0.3.0 or later? Tidewatch offers this version on its own, or choose Check for Updates… in the menu bar. New here? Open Tidewatch-0.4.3.dmg, drag Tidewatch to Applications, start it and choose Connect to Claude Code in the menu bar.

Requires macOS 14.4+ on Apple silicon.
