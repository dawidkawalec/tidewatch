Tidewatch 0.3.0

New in this release

  • Automatic updates. Tidewatch checks for a new version once a day and asks before installing it. You can also choose Check for Updates… in the menu bar. Every update is signed, and Tidewatch refuses one that is not.
  • The menu bar shows the installed version.
  • New home: kawalec.pl/tidewatch, with looping recordings of the widget.

Install

Open Tidewatch-0.3.0.dmg, drag Tidewatch to Applications, start it and choose Connect to Claude Code in the menu bar. Coming from 0.2.0? Install this version once by hand; later versions arrive on their own.

Requires macOS 14.4+ on Apple silicon.
