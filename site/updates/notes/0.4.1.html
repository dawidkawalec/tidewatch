Tidewatch 0.4.1

New in this release

  • Lighter glass. The widget's glass now blurs what is behind it only a little, so you can still see your code through it.
  • Glass settings. Choose Glass Blur (Light, Medium, Strong) and Glass Tint (Lighter, Default, Denser) in the menu bar. Changes apply at once.
  • When the review lamp fades. Review Lamp Fades in the menu bar: after 5, 10 or 30 minutes, or never until you open the session.
  • Every row shows its conversation and project. The first line is the conversation's title, the second its status and project ("Idle · atlas"), for windows with one tab or several.

Install

Already on 0.3.0 or later? Tidewatch offers this version on its own, or choose Check for Updates… in the menu bar. New here? Open Tidewatch-0.4.1.dmg, drag Tidewatch to Applications, start it and choose Connect to Claude Code in the menu bar.

Requires macOS 14.4+ on Apple silicon.
