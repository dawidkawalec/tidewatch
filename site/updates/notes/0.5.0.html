Tidewatch 0.5.0

New in this release

  • T3 Code support. Sessions running in T3 Code get their own lamp with a T3 glyph. A click opens that exact thread in T3 Code. When the thread is not known yet (a session started before the update), the click opens the project in T3 Code instead of Finder.
  • T3 sessions grouped by project. All T3 Code sessions run under one T3 server, so they are grouped by project folder, the same way T3 Code's sidebar shows them.
  • Steadier host detection. A session that was idle while Tidewatch updated is recognised from Claude Code's own session list, so its lamp and its click are right before its next event.

VS Code and terminal sessions work as before.
